Eight field notes for learning local AI

Keep the knowledge.
Make the machine useful.

Find the right source. Make room for a longer conversation. Follow a failed tool call. Learn what to change, and how to tell whether it helped.

By SundogThe revised reading edition

I like machines people can keep, and explanations that leave the next person with more choices. Pick the problem you have. Each article follows a concrete example into the engineering, with sources and somewhere useful to go next.

New to the territory? Start with retrieval for an everyday task, or conversation memory for a local constraint. Coding and agent articles assume a working runner; the Spark walkthrough is for its operators.

The eight revised articles include new teaching diagrams. Sundog's character portraits are awaiting the established Grok Bot references; the rejected images have been removed from this edition. This is a review preview.
