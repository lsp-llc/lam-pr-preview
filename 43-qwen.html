Qwen3.6 (27B)
27B ~14 GB 256K ctx Vision Apache 2.0 Tool Use
Hugging Face card for official Qwen/Qwen3.6-27B (repo created 2026-04-21): Causal Language Model with Vision Encoder. Number of Parameters: 27B. 64 layers, hidden dimension 5120, layout 16 × (3 × (Gated DeltaNet → FFN) → 1 × (Gated Attention → FFN)). Gated Attention: 24 Q heads / 4 KV heads, head dim 256. Gated DeltaNet: 48 V / 16 QK linear-attention heads, head dim 128. Context: 262,144 natively and extensible up to 1,010,000 tokens. Apache 2.0. The card says this is the first open-weight Qwen3.6 variant after the Qwen3.5 series. VRAM is not stated. HF card last verified 2026-08-20.
Strengths
  • 27B dense + vision encoder (HF card)
  • 256K native context, extensible to 1.01M (card)
  • Apache 2.0
  • Official successor to the live Qwen3.5 27B card
Weaknesses
  • VRAM GB is a catalog Q4 estimate (Params × 0.5), not printed on the HF card
VRAM Breakdown
  • Q4 est. ~14 GB weights (27B × 0.5). Not stated on the HF card. KV cache is extra.

Qwen3.8 (27B)
27B ~14 GB 256K ctx Vision Apache 2.0 Tool Use
Hugging Face card for Qwen/Qwen3.8-27B (repo created 2026-08-05): Causal Language Model with Vision Encoder; native image and video. Number of Parameters: 27B. 64 layers, hidden dimension 5120, layout 16 × (3 × (Gated DeltaNet → FFN) → 1 × (Gated Attention → FFN)). Gated Attention: 24 Q heads / 4 KV heads, head dim 256. Thinking mode is on by default and can be disabled; reasoning_effort levels on the card are xhigh (default), medium, and low. VRAM is not stated. HF card last verified 2026-08-20.
